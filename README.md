# Meu Portal de Entretenimento Digital

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar uma página web temática utilizando HTML5 e CSS3, aplicando conceitos fundamentais de estruturação, estilização e organização visual de páginas web.

O tema escolhido foi **“Meu Portal de Entretenimento Digital”**, reunindo conteúdos relacionados a filmes, séries, músicas, podcasts, games e tecnologia em uma interface moderna com estética tecnológica.

---

# Objetivos da Atividade

- Utilizar HTML para estruturar o conteúdo da página;
- Aplicar diferentes formas de CSS:
  - Inline;
  - Interno;
  - Externo;
- Trabalhar com classes e IDs;
- Organizar o layout utilizando Flexbox;
- Aplicar boas práticas de estilização e organização do código;
- Criar um visual moderno e responsivo.
